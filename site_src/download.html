    Which one do I want?

    You haveDownload
    A Windows PCThe web installer. It is small and fetches the right package for your processor.
    An Android phone or tabletThe installer app (about 1 MB). It finds out which processor you have and downloads the right PythonOS app.
    LinuxThe package for your distribution (.deb, .rpm, Arch), or the tarball for any other.
    A PC to try it onThe bootable ISO, written to a USB stick. Your disk is not touched. Add a data disk to keep your files.
    VirtualBox or VMwareThe .ova. It comes with a data disk and an empty disk for the installer.
    QEMU, KVM or ProxmoxThe .qcow2, plus the data disk next to it.
    A MacThere is no Mac version. Use Docker or a virtual machine.

    More about each: what the packages are and how they update.

    Check what you downloaded

    Every release lists the SHA-256 of each file in SHA256SUMS.

    # Windows (PowerShell)
Get-FileHash .\PythonOS-*-web-setup.exe

# Linux
sha256sum -c SHA256SUMS --ignore-missing

# Build provenance (GitHub CLI)
gh attestation verify FILE --repo Kalmai221/PythonOS

    Docker

    docker run -it --rm -v pythonos-data:/data ghcr.io/kalmai221/pythonos

    For amd64 and arm64. The volume keeps your accounts, files, settings and updates; without it everything is forgotten when the container stops.
