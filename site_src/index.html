A terminal operating system, written in Python.

PythonOS has a shell, user accounts, a file system, an editor, an app store and its own task manager. You use it by typing, in a terminal window, on a phone, or as a bootable USB stick.

Download Get started Browse the apps

Free and open source. Runs on Windows, Android, Linux, a bootable USB, virtual machines and Docker. It updates itself.

you@pyOS:~$

What is in it

  • A real shellPipes, redirects, &&, ||, background jobs, variables, aliases and tab completion. About 120 commands, all documented with man.
  • Accounts and permissionsUsers with roles, passwords, lock and idle logout. Deleted files go to a trash you can undo.
  • Its own toolsA text editor, a full-screen file manager (fm), a task manager that shows only PythonOS, and a settings app.
  • An app storeOver seventy apps and games. Each app says what it may do before you install it, and is held to that while it runs.
  • ContainedThe live USB never gives access to the Linux underneath: no shell, no login, only PythonOS. A read-only emergency console helps when something breaks.
  • Updates itselfRun updatecheck. The core updates in place; a new package for your system is announced when one is needed.

Where it runs

WindowsAn installer and a portable version. Intel/AMD and ARM. AndroidA phone or tablet app, with a 1 MB installer that picks the right one. Linux.deb, .rpm, Arch package or a tarball, for any processor. Bootable USBStart a PC from a stick without touching its disk. Installing is optional. Virtual machineAn .ova for VirtualBox and VMware, a .qcow2 for QEMU. DockerA container image for amd64 and arm64.

Not sure which one? The download page picks one for your computer. What each one is, and how it updates.

Build for it

Apps are small Python programs described by one JSON file. The documentation covers the package format, what an app may do, how to test it, and how to send it in as a pull request.
