Check what you downloaded

Every release lists the SHA-256 of each file in SHA256SUMS, signed by the release workflow.

Windows (PowerShell)

Get-FileHash .\PythonOS-*-web-setup.exe

Linux / macOS

sha256sum -c SHA256SUMS --ignore-missing
